# Task 3 - Password Maker

This Python project creates a random password using letters and numbers.

## Features

* User chooses the password length
* Generates a random password
* Uses uppercase and lowercase letters
* Includes numbers
* Checks the password length
* Handles invalid input

## Python Concepts

* Functions
* For loops
* Conditions
* Strings
* Modules
* User input
* Exception handling

## How to Run

Run this command:

```bash
python task3_password_generator.py
```

## Example

```text
===== PASSWORD MAKER =====

Enter password length: 10

Your password is: G7mQ2pL9xA
```

## Main File

`task3_password_generator.py`

## Purpose

This project helps practice Python strings, loops, functions, modules, and input validation.
