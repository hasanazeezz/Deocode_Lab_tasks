# Task 2 - Personal Expense Tracker

This is a simple Python program that keeps track of expenses entered by the user.

## Features

* Add expense amounts
* Calculate total spending
* Count expenses
* Reject negative values
* Handle invalid input

## Python Concepts

* Variables
* Functions
* While loops
* Conditions
* Arithmetic
* User input
* Exception handling

## How to Run

Run this command:

```bash
python task2_expense_tracker.py
```

## Example

```text
===== EXPENSE TRACKER =====

Enter an expense or type q to finish: 15
Expense recorded.
Total so far: 15.0

Enter an expense or type q to finish: q

===== FINAL SUMMARY =====
Total spent: 15.0
Number of expenses: 1
```

## Main File

`task2_expense_tracker.py`

## Purpose

This project helps practice loops, calculations, variables, input validation, and exception handling in Python.
