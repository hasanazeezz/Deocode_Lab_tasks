# Task 1 - Simple To-Do Manager

This project is a basic Python program for keeping track of daily tasks.

## Features

* Add a new task
* View saved tasks
* Remove a task
* Simple menu
* Handles incorrect input

## Python Concepts

* Lists
* Functions
* Loops
* Conditions
* User input
* Exception handling

## How to Run

Run this command:

```bash
python task1_todo_list.py
```

## Main File

`task1_todo_list.py`

## Purpose

This project helps practice basic Python concepts such as lists, loops, functions, and user input.
